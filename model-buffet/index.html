Real-time voice & live models

Speech-in, speech-out models built for conversation — they listen and answer while you're still mid-thought, instead of transcribing, thinking, then reading a reply aloud. The pick for voice agents, phone bots, and hands-free assistants.

Model What it does Access Note
Gemini 3.8 Live
Google · Sept 15, 2026
 Native speech-to-speech model for fast, natural conversation — takes text, image, audio, and video in, with about 128K context and automatic switching among 97 languages. Gemini API and AI Studio; rolling into Search Live Positioned as the cost-effective base for scalable voice agents, where latency matters more than deep reasoning. blog.google →
Gemini 3.8 Live Extended Thinking
Google · Sept 15, 2026
 Keeps the conversation going while it reasons through multistep tasks and runs tools in the background. Gemini API and AI Studio; Gemini Live; Workspace — Docs (Pro/Ultra), Gmail, Keep Ranked #1 on Artificial Analysis' speech-to-speech leaderboard at launch. techrepublic.com →
GPT-Live
OpenAI · July 2026
 A new generation of voice models on a full-duplex architecture — it can listen and speak at the same time, so talking to it feels closer to a real conversation. OpenAI voice products, launched July 2026 OpenAI's pitch is conversation that flows rather than trading turns; the launch post lists which surfaces have it. openai.com →
GPT-Realtime-2

Model routers

A different category from the harnesses above — you don't pick the model here, the router does, per request, based on the prompt itself.

Router What it does How it decides Note
ChatGPT Auto
Native, built into GPT-5.x/6
 Switches between Instant, Thinking, and Pro tiers inside a single conversation. Real-time complexity, tool-need, and intent detection OpenAI's own default now — the router escalates a quick question to the slower "thinking" model automatically instead of asking you to choose. openai.com →
OpenRouter
Auto Router
 Sits in front of 300+ models from every lab in this sheet; set the model to auto and it picks per prompt. Aggregate 7-day usage data per task type, across millions of requests The closest thing to a market-priced router — it's effectively crowd-sourcing "what's working best right now" instead of a fixed benchmark. openrouter.ai →
Martian
Decision-engine API
 A drop-in layer that takes a prompt meant for one model and reroutes it to whichever backend model suits it best. Learned routing policy over cost, quality, and latency Built for teams who want router logic in their own product rather than a hosted chat surface. stackshare.io →
Not Diamond
Model-selection API
 Determines which LLM is best suited to answer a given query before it's sent. Per-query classifier, tunable to your own eval data Positioned for developers embedding routing logic directly into an app rather than end users picking a model by hand. github.com/Not-Diamond →

Always-on agents

A different job from a router or an IDE plugin — this is an agent that runs continuously on its own hardware and takes action without being asked each time. Hermes and OpenClaw do it self-hosted and model-neutral; Grok Bot and Meta's Muse do the same job as locked-in hosted services.

Framework What it is Deployment Note
Hermes Agent
Nous Research · Feb 2026
 Self-hosted agent with persistent memory across sessions; codifies repeated successful tasks into reusable, human-readable skill files. Self-hosted
model-neutral — OpenRouter, OpenAI, Anthropic, or your own endpoint		 Claimed the #1 spot on OpenRouter by daily token usage within its first three months of release. hermes-agent.org →
OpenClaw
OpenClaw Foundation · MIT
 Self-hosted personal agent that executes real actions — shell commands, file management, web automation — via 100+ prebuilt AgentSkills, not just chat replies. Self-hosted
model-agnostic — connects to Claude, GPT, and others		 Went from a November 2025 side project to 355K GitHub stars by April 2026; now stewarded by an independent non-profit foundation. openclaw.ai →

 An "always-on teammate," not a chat window — runs continuously on its own cloud machine to work sales outbound, CRM updates, email, expense handling, and bug reproduction end to end. Hosted SaaS only
runs on xAI's cloud, not self-hostable or model-choosable		 Same always-on job as Hermes and OpenClaw, but vendor-locked: access requires a SuperGrok, Cursor Pro, or Cursor Teams subscription. x.ai →
